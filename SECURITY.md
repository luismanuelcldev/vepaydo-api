# Security Policy

## Supported Versions

Only the latest release targeting the current active .NET Long Term Support (LTS) / STS baseline receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The VePayDO engineering team takes security and data privacy seriously. If you discover a potential security vulnerability within this repository, please do not disclose it publicly via GitHub issues or discussions.

Instead, report it responsibly through private security advisories or by contacting the lead author directly:

- **Security Contact:** luismanueldelacruz0000@gmail.com
- **Author:** Luis Manuel De La Cruz Ledesma

### Information to Include in Your Report

Please provide sufficient details to help us reproduce and remediate the issue:

- Type and severity of the suspected vulnerability.
- Location in the codebase (project, class, method, or endpoint).
- Step-by-step instructions or proof-of-concept payload to reproduce the issue.
- Potential impact on tenants, data isolation, or runtime execution.

### Response Timeline

- **Initial Acknowledgment:** Within 48 hours of receipt.
- **Assessment & Triage:** Within 5 business days.
- **Resolution & Disclosure:** Coordinated release once a patched build is verified.
